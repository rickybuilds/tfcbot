# `!fixbj` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Let configured admins refund and cancel a stuck blackjack table in the current channel.

**Architecture:** Add an atomic cancellation operation in the blackjack domain module that refunds active seat stakes and unsettled hand stakes through the existing point ledger, marks seats refunded and hands settled with result `refunded`, and marks the round cancelled. Register `!fixbj` in point game commands, restrict it to the configured admin role, clear the timer and refresh the table panel.

**Tech Stack:** Node.js, Discord.js, SQLite point ledger.

**Spec:** `docs/superpowers/specs/2026-11-13-fixbj-design.md`

## Global Constraints

- The command is admin-only and scoped to the current channel.
- Refund all outstanding seat and hand stakes, including split and double wagers.
- Cancel the round atomically with ledger refunds; preserve historical records.
- Stop the round timer and refresh the existing table message.

## Review Focus

- Joining rounds refund active seat stakes and close the round.
- Playing rounds refund only unsettled hands; split and double stakes are reflected in hand stake totals.
- No active round returns a clear response without ledger changes.
- Non-admin and non-casino channel calls cannot mutate state.
- Repeated command delivery cannot refund twice due to round state and operation idempotency.
